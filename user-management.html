📝 新規ユーザー追加方法

新規ユーザーの追加には2ステップ必要です（service_role権限が必要なためブラウザから直接登録できません）。Supabase Dashboardで操作してください。

  1. Step 1: Supabase Auth でユーザーを作成 Authentication → Users を開き、右上の Add user → Create new user をクリック。
    メールアドレスと初期パスワードを入力 → Auto Confirm User をONに → Create user。
  2. Step 2: profiles テーブルにロール情報を登録 SQL Editor で以下のSQLを実行（メールアドレス・ロール・表示名を変更）： 
    -- 新規ユーザーを profiles に登録
-- 下記3箇所の <...> を実際の値に置き換えてください
INSERT INTO public.profiles (id, organization_id, role, display_name, email)
SELECT
  u.id,
  '00000000-0000-0000-0000-000000000001'::uuid,
  '<ROLE>',                    -- admin / manager / viewer
  '<DISPLAY_NAME>',            -- 表示名（例: 田中）
  u.email
FROM auth.users u
WHERE u.email = '<EMAIL>'      -- 追加するメールアドレス
ON CONFLICT (id) DO UPDATE SET
  role = EXCLUDED.role,
  display_name = COALESCE(public.profiles.display_name, EXCLUDED.display_name),
  email = EXCLUDED.email,
  updated_at = NOW();
📌 補足: Step 2 完了後、本ページをリロード（F5不可なら更新ボタン）すると新ユーザーが一覧に表示されます。新規ユーザーはStep 1で設定した初期パスワードで login.html からログイン可能になります。
